# Neural Knowledge by TANK · refreshed 2026-10-07 · d58208d52ddc

This repository is the source of truth for every TANK wire type: Connect RPC services, realtime WebSocket frames,
bus events and block (card) schemas. Proto definitions live under `proto/tank/<domain>/v1/*.proto`; generated Go,
TypeScript and Python bindings are committed under `gen/` on purpose, not fetched at build time. Consumers are the
Go module `github.com/tactical-agent-neural-knowledge/contracts/gen/go` and the npm package
`@tactical-agent-neural-knowledge/contracts` (published to GitHub Packages).

## Commands
- Regenerate: `make gen` (runs `buf generate` via `npx @bufbuild/buf`)
- Lint: `make lint` (verified clean this refresh)
- Breaking check vs main: `make breaking`
- Build Go bindings: `make build` (`go build ./...`)
- Everything CI runs: `make check` (lint, gen, build, then fails if `gen/` is stale)

## Areas
- `.` — repo root: Makefile, buf config, go.mod, README. Read `.neural/neurons/root.md`.
- `.github` — the single CI/CD workflow (check + publish-ts). Read `.neural/neurons/github.md`.
- `proto` — the 26 `.proto` domain packages that are this repo's actual product. Read `.neural/neurons/proto.md`.

## Rules
- "Wire names stay neutral (`Channel`, not `Tread`); product vocabulary lives in the clients." (CLAUDE.md)
- "One proto package per domain, version suffix `v1`. Generated code committed, not fetched at build time." (CLAUDE.md)
- Hard prohibitions (CLAUDE.md): renumbering or reusing field numbers; removing a field before every client has
  shipped without it; editing `gen/` by hand; changing plugin versions without regenerating everything in the same PR.
- "Changes are additive-first: add fields, ship every client, wait for the mobile build to land, then remove. `buf
  breaking` enforces the wire half." (README.md)

## Before changing anything
- Edit `.proto` files only; never hand-edit anything under `gen/`.
- Run `make gen` after any proto change and commit the regenerated `gen/` diff in the same PR — CI fails the build
  otherwise (`gen/ is stale. Run 'make gen' and commit the result.`).
- Run `make lint` and, for a PR against main, `make breaking` before pushing; CI runs `buf breaking` only on
  pull_request events, not on direct pushes to main.
- `make check` reproduces lint + gen-freshness + Go build locally; it does not run the `gen/ts` TypeScript compile
  that CI also checks.

## Neural Knowledge
This layer (`AGENTS.md` plus `.neural/`) is generated by TANK and refreshed automatically on every push to the
default branch. Hand edits are overwritten on the next refresh — change the source code or `CLAUDE.md` instead if
something here needs to be different.
