# Neural Knowledge by TANK · refreshed 2026-10-16 · 96c9e69403fd

`contracts` is the single source of truth for every wire format in TANK: 29 Protobuf/Connect packages
under `proto/tank/<domain>/v1/`, covering auth, workspaces, Treads (wire name `Channel`), agents, crew,
boards, books, canvas, remediation, security and more. The generated Go, TypeScript and Python clients
are built with buf v2 and **committed** under `gen/`, so consumers import them instead of regenerating.
Nothing here runs a server: it is a schema repository whose job is to change without breaking its
downstream consumers (api, web, mobile, sdk-ts, agent-control, agent-runner, knowledge).

## Commands

- `make` is **not installed in the agent sandbox** — every Makefile target fails with `spawn make ENOENT`. Run the underlying commands directly instead:
- `npx --yes @bufbuild/buf lint` — STANDARD rules minus `PACKAGE_VERSION_SUFFIX` (verified passing)
- `npx --yes @bufbuild/buf breaking --against '.git#branch=main'` (verified passing)
- `npx --yes @bufbuild/buf generate` — regenerates `gen/go`, `gen/ts/src`, `gen/python`
- `go build ./...` — Go 1.26 toolchain is present in the sandbox; downloads modules on a cold cache
- `npm install && npm run build` in `gen/ts` — the tsc compile CI performs
- CI's full gate (what `make check` would run): lint, breaking, `buf generate` + `git diff --exit-code --stat gen/`, go build, tsc

## Rules

From `CLAUDE.md`, hard prohibitions:

> Renumbering or reusing field numbers; removing a field before every client has shipped without it;
> editing `gen/` by hand; changing plugin versions without regenerating everything in the same PR.

From `CLAUDE.md`, decided — do not re-litigate:

> Wire names stay neutral (`Channel`, not `Tread`); product vocabulary lives in the clients. One proto
> package per domain, version suffix `v1`. Generated code committed, not fetched at build time.

From `buf.yaml`: lint is `STANDARD` with `PACKAGE_VERSION_SUFFIX` excepted; breaking is checked at
`FILE` level, so moving a message between files is a break even when the wire is unchanged.

## Before changing anything

- Edit `proto/`, never `gen/`. Regenerate with `buf generate` and commit the output in the same change.
- Run `buf lint` and `buf breaking --against '.git#branch=main'` before opening a PR; CI enforces both,
  plus a diff-after-regenerate check that fails on any drift in `gen/`.
- Additive first: add a field, ship every consumer, then remove the old one in a later release.
- A PR green on `ci.yml`'s `check` job is the bar. A push to `main` publishes a canary npm package; a
  `v*` tag publishes a release — merging to `main` is already a publish.

## Neural Knowledge

This layer is generated by TANK. It lives in `.neural/` (the deterministic map in `.neural/map.yaml`
and `.neural/index.json`, plus one neuron file per area under `.neural/neurons/`) and is summarised in
this file. It is refreshed automatically on every push to the default branch, which rewrites both the
neuron files and `AGENTS.md` wholesale — any edit made here by hand is overwritten on the next refresh,
so correct the code or the documents the layer is read from instead.
