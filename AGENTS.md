# Neural Knowledge by TANK · refreshed 2026-10-17 · fee5860e47dd

This repository is the wire contract for the TANK platform: hand-written `.proto` files under `proto/`, with generated Go, TypeScript, and Python code committed under `gen/`. Every service in the platform (web, mobile, agent runner, control plane) consumes these definitions; a break here is a production incident, which is why the breaking-change check is the first gate on every pull request.

## Commands

```
# Lint protos (buf must be on PATH, or uses npx on cold cache)
npx --yes @bufbuild/buf lint

# Regenerate gen/ from proto/
npx --yes @bufbuild/buf generate

# Breaking change check vs main (PR branches only)
npx --yes @bufbuild/buf breaking --against '.git#branch=main'

# Build Go (requires Go 1.26+ on PATH)
go build ./...

# Everything CI runs (requires make)
make check
```

Note: `make` is often absent in agent sandboxes. Run the underlying commands above directly.

## Areas

- `.` — root config (Makefile, buf.gen.yaml, buf.yaml, CLAUDE.md); see `.neural/neurons/root.md`
- `.github` — CI workflows (ci.yml, security.yml); see `.neural/neurons/github.md`
- `proto` — 29 proto domains, all service definitions; see `.neural/neurons/proto.md`

## Rules

From `CLAUDE.md`:
- Renumbering or reusing field numbers is forbidden.
- Removing a field before every client has shipped without it is forbidden.
- Editing `gen/` by hand is forbidden.
- Changing plugin versions without regenerating everything in the same PR is forbidden.
- Wire names stay neutral (`Channel`, not `Tread`); product vocabulary lives in the clients.
- One proto package per domain, version suffix `v1`.
- Generated code is committed, not fetched at build time.

From `buf.yaml`:
- `lint.use: [STANDARD]` minus `PACKAGE_VERSION_SUFFIX`.
- `breaking.use: [FILE]` — FILE-level, so moving a message between files is breaking even when the wire is unchanged.

## Before changing anything

1. Run `npx --yes @bufbuild/buf lint` — must pass before opening a PR.
2. Any proto change requires regenerating `gen/`: run `npx --yes @bufbuild/buf generate` and commit the result in the same PR. CI enforces this with `git diff --exit-code --stat gen/`.
3. Check for breaking changes on PR branches: `git fetch --no-tags origin main:main && npx --yes @bufbuild/buf breaking --against '.git#branch=main'`.
4. `go build ./...` must succeed; TypeScript is checked by CI (`npm install && npm run build` in `gen/ts`).
5. Plugin versions in `buf.gen.yaml` must stay in sync with `go.mod` (protoc-gen-go v1.36.4 ↔ `google.golang.org/protobuf v1.36.4`, connect-go v1.18.1 ↔ `connectrpc.com/connect v1.18.1`).

## Neural Knowledge

This layer is generated by TANK, lives in `.neural/`, and is refreshed on every push to the default branch. The files `.neural/neurons/root.md`, `.neural/neurons/github.md`, and `.neural/neurons/proto.md` are rewritten each refresh. Edits by hand are overwritten on the next push.
