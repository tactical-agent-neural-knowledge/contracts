# Neurons · proto

refreshed 2026-10-07 · d58208d52ddc

- 26 domains now, one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. Since the last refresh: `board`, `books`, `canvas` and `security` were added wholesale (549, 333, 302 and 262 lines); `agent`, `agentctl`, `events`, `realtime`, `topo` and `workspace` grew. `CLAUDE.md`: "One proto package per domain, version suffix `v1`."
- `proto/tank/board/v1/board.proto` is Neuralboards: an infinite board where a `Frame` can hold the running application itself (`AppFrame`), not a picture of one. `AppFrame.drawn_from_sha` vs. the app's current commit is how a frame learns it `moved_on`; `BoardObject.meta` is one opaque string for editor-only relationships (component instance, named style, layout, pin) so a renderer that ignores it still draws correctly.
- `proto/tank/books/v1/books.proto` is Neuralbooks: double-entry bookkeeping surfaced as customers, invoices, payments, expenses, a cash summary, bank import/matching and an accountant export. All amounts are integer cents; `Settings.stripe_secret_key` is write-only (send empty to leave it alone, read back only `stripe_key_hint`'s last four chars) — never round-trip the real key through a client.
- `proto/tank/canvas/v1/canvas.proto` is Neuralcanvas: pages built from `Block`s that cite what they were written from. `Decision` blocks are answerable (what/who/when/why/supersedes) and carry `needs_revisiting`; `Live` blocks are filled in by the server at read time so the page is never stale about its own numbers — the comment states the thesis: "the failure of every wiki is... nobody can tell what is still true."
- `proto/tank/security/v1/security.proto` (Neuralsecurity Phase 0) has one rule in its header comment: "Controls are the primitive; frameworks are views over them" — one `Control` registry, `FrameworkClause`s (SOC 2 first) map onto it, never a second set of facts. `ControlState.UNKNOWN` is mandatory for a stale check ("a stale check reports UNKNOWN, never its last answer"); `NOT_APPLICABLE` and `PARTLY` both require a non-empty `reason`.
- Product vocabulary never reaches the wire. `proto/tank/channel/v1/channel.proto:7`: a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." Same pattern for boards/canvas: wire says Board/Canvas, product says board/page as drawn in each proto's own header comment.
- `optional` is deliberate presence, not nullability: unchanged-field semantics in `UpdateChannelRequest`, "this replaces nothing" in `topo.proto`'s `supersedes_id`, the empty-vs-unconfigured split in `TopoPreferences.configured`. Dropping `optional` to tidy a field silently changes meaning.
- `proto/tank/agentctl/v1/agentctl.proto` (now 913 lines) is the runner ↔ control-plane contract only, authenticated by per-run `RUN_TOKEN`. `RunnerService` grew board tools (`ListBoards`/`ReadBoard`/`DrawOnBoard`/`ArrangeBoard`), books tools (`BooksSummary`/`BooksCreateInvoice`/`BooksRecordExpense`/`BooksRecordPayment`/`BooksReport`) and canvas tools (`ReadCanvas`/`AskCanvas`/`WriteUpThread`) alongside the thread/approval primitives; `ControlService.RefreshNeuralKnowledge` keeps one standing thread per repository for refreshes and is idempotent while one is active.
- `ControlService.RegisterDeployment`/`GetDeployment` host a repository TANK did not generate on TANK's cluster (`<slug>.tank.chat`); `GetDeploymentResponse.managed` distinguishes that from a TANK-generated repo (`agenture-<slug>`), and `workflow_present` tells the caller whether `.github/workflows/tank.yml` exists yet. `agent.proto`'s `TreadDeployment` mirrors the same fields for a Tread's own hosting.
- `proto/tank/events/v1/events.proto` is the NATS JetStream envelope (`Envelope.id` is the `Nats-Msg-Id` idempotency key, payload a `google.protobuf.Any`). New since last refresh: `CanvasBlockChanged`/`CanvasChanged`/`CanvasEditing` and `BoardObjectsChanged`/`BoardChanged`/`BoardPointer`, delivered per-block/per-object so two people editing different parts see each other instead of a reload.
- `proto/tank/realtime/v1/realtime.proto` gateway frames grew to match: `Subscribe`/`Unsubscribe` now carry `canvas_ids`/`board_ids`, and `ClientFrame`/`ServerFrame` oneofs added `CanvasEditingFrame`/`canvas_editing` and `BoardPointerFrame`/`board_pointer` — rate-limited like typing, never stored.
- Cross-package imports make FILE-level breaking bite across domains: `events.proto` now imports `board` and `canvas` on top of `admin`/`agent`/`blocks`/`channel`/`files`/`huddle`; a field removed from `board.proto` or `canvas.proto` now fails the breaking check in `events.proto` too.
- Never renumber or reuse a field number, never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` / the PR's breaking check catches the first; nothing but discipline catches the second.
