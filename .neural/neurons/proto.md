# Neurons · proto

refreshed 2026-10-08 · a887d51f4d82

- 27 domains, one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`." Five domains were added since the last refresh: `board`, `books`, `canvas`, `remediation`, `security`.
- Product vocabulary never reaches the wire. `proto/tank/channel/v1/channel.proto:7`: a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." A Radar is `CHANNEL_TYPE_MONITOR = 5`, implemented in `tank.monitor.v1`.
- Unread-count trap, and the two comments disagree: `Channel.last_seq` (channel.proto:44) still says "unread = last_seq - last_read_seq", while `ChannelReadState.unread_count` (channel.proto:77-85) documents why that arithmetic is wrong — thread replies and deleted messages also consume a `channel_seq`. Use `unread_count`; it is `optional` so a client can tell "server said zero" from an older server saying nothing.
- `optional` is used throughout as deliberate presence, not nullability: unchanged-field semantics in `UpdateChannelRequest`, "this replaces nothing" in `DecideBenchmarkRequest.supersedes_id` (topo.proto), the empty-vs-unconfigured distinction in `TopoPreferences.configured` (workspace.proto). Dropping `optional` to tidy a field silently changes meaning.
- `proto/tank/workspace/v1/workspace.proto` is the biggest file (719 lines) and `GetBootstrap` is its point: one call on app open, everything else lazy.
- `proto/tank/agentctl/v1/agentctl.proto` (1045 lines, the biggest proto) is the runner ↔ control-plane contract: authenticated by the per-run `RUN_TOKEN`, all ids Snowflake decimal strings. This refresh added six narrow `ControlService` RPCs (`BindChannelRepo`, `UnbindChannelRepo`, `SetChannelRepoAccess`, `CreateGitHubConnectState`, `SetChannelAgentSettings`, `SetWorkspaceAgentPolicy`) because the messaging core's app role has only USAGE+SELECT on schema `agent` — it cannot issue the INSERT/DELETE it used to send straight at `agent.repo_bindings` etc., so each write is now a call instead of a wider grant.
- `proto/tank/events/v1/events.proto` is the NATS JetStream envelope (`Envelope.id` is the `Nats-Msg-Id` idempotency key, payload a `google.protobuf.Any`) and also the domain with the widest blast radius: it imports 13 other package files (admin, agent, blocks, board, canvas, channel, files, huddle, message, monitor, presence, topo, workspace). A FILE-level breaking change to any of those fails the check here too.
- `proto/tank/realtime/v1/realtime.proto` is the WebSocket gateway, binary protobuf by default (`?enc=json` only for debugging). `Event.cursor` is the JetStream stream sequence the client persists and replays with `Resume`; `PresenceSubscribe` caps at 500 ids and *replaces* the set rather than adding to it.
- `proto/tank/richtext/v1/richtext.proto` holds the `RichText` AST and states the rule plainly: "Markdown is never the storage format." Anything accepting user-authored text should take `RichText`, not a string.
- `proto/tank/blocks/v1/blocks.proto` is the agent UI vocabulary — `PlanCard`, `DiffPreview`, `CiStatus`, `ApprovalPrompt`, `ToolLog`, `StatusCard` — plus `GateKind` (PLAN, SCOPE_CHANGE, MERGE, DEPLOY, DESTRUCTIVE_TOOL, BUDGET_INCREASE). A `BlockAction` travels client → server → owning agent as an event, not as an RPC.
- `proto/tank/books/v1/books.proto` (new) is Neuralbooks: double-entry money kept in integer cents. `Settings.stripe_secret_key` is write-only (reads back only as a `stripe_key_hint` suffix). `GetInvoiceRequest.rotate` mints a new share link and kills the old one in the same call — the share token is stored as a hash, so there is no "read the link back" path, and rotate exists precisely because of that.
- `proto/tank/remediation/v1/remediation.proto` (new) is the seam between the registry that judges (messaging core) and the engine that fixes (agent control plane) — deliberately not the same program. `Disposition` defaults to `PROPOSE`; `AUTO_APPLY` requires a declared `Class` with `reversible=true`, an `undo`, and never `lockout_risk=true`. `Remediation.forbidden_paths` keeps a run from touching the controls/probes/mappings that judge it.
- `proto/tank/security/v1/security.proto` (new) models "controls are the primitive, frameworks are views over them" — a `Control` is one fact with an owner, a check and evidence; a `FrameworkClause` only maps onto existing controls. `ControlState.UNKNOWN` is forced whenever evidence is stale (`max_age_seconds` exceeded) rather than returning the last known answer — `SecurityService` is read-only except `Evaluate`, which only re-runs checks.
- Adding a domain needs only a new `proto/tank/<domain>/v1/<domain>.proto` plus `make gen`: managed mode supplies `go_package` (9 files override it anyway: billing, books, canvas, catalog, monitor, platform, remediation, security, topo), and lint's `PACKAGE_VERSION_SUFFIX` exemption is already in `buf.yaml`. The TS barrel at `gen/ts/src/index.ts` is hand-written and covers only 14 of the 27 domains — it will not pick up a new one.
