# Neurons · proto

refreshed 2026-10-10 · e52a377a71d9

- 27 domains now, one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. Five are new since the last refresh: `board`, `books`, `canvas`, `remediation`, `security`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`."
- `board.proto` is Neuralboards: an infinite board whose `AppFrame` can hold the *running application* at a commit, not a screenshot of one — a person clicks into it and calls `RequestChange`. `BoardSlice` is a named export region; `BoardEmbedRequest`'s link is itself the credential (rotate to revoke, same pattern as an invoice share link).
- `books.proto` is Neuralbooks: double-entry bookkeeping surfaced as customers/invoices/payments/expenses/`CashSummary`, all integer cents. `ReadReceipt` turns an attachment into an expense; `ImportBankTransactions` + `MatchBankTransaction` reconcile a bank feed line against an invoice or expense.
- `canvas.proto` is Neuralcanvas: a page that cites what it was written from (`Source`) and says so when that drifts. `Live` blocks are filled in by the server on read, never stored stale. `WriteFromThread` turns a thread's decisions into the first draft; `Ask` answers a question from the passage, not a search hit.
- `remediation.proto` is the other half of `security.proto` by design, split across two services on purpose: the messaging core's control registry judges and calls `SubmitFinding`, the agent control plane's remediation engine fixes and owns the GitHub App/sandboxes/gate engine. Neither side may do the other's job — "a system that can mark its own homework is not a security system" (remediation.proto:20).
- `remediation.proto`'s `Severity`/intervention default is `PROPOSE`: a remediation opens a PR a human merges. `AUTO_APPLY` only applies to a short declared `Class` list, each with its reverse written down (`ListClasses` is literally the list a buyer's security team gets shown). `SubmitFinding` is idempotent on `(finding_id, control_version)` so an hourly evaluation doesn't open duplicate PRs.
- `security.proto`'s rule: Controls are the primitive, frameworks (`FrameworkClause`, SOC 2 today) are just a mapping over them — never a second set of facts. A `Control` with no evidence is `NOT_YET` even if everyone's sure it holds; a stale check reports `UNKNOWN`, never its last answer. `ClauseCoverage` state is derived (worst of its controls), never stored.
- `agentctl.proto` gained `RunContext.skip_neural_knowledge` (true when the Tread turned off Neural Knowledge, or this run is the control half of a measurement) and `RunContext.task_class` (`"single_area"` skips the plan stage on the cheaper model, `"multi_area"` doesn't; empty on older runs). `RefreshNeuralKnowledge` is the RPC this very refresh runs through — idempotent while one is already active per repository, keeps one standing thread per repo. `OpenThread` is how the platform (not a human) opens a thread, e.g. for that refresh.
- `agent.proto`'s `TreadSettings.pull_requests` is `"review"` (default, mentions `pr_reviewer_ids`) or `"merge_when_green"` (TANK watches checks and merges) — sits next to `auto_accept_plans`. `read_neural_knowledge` is the per-Tread switch `agentctl.skip_neural_knowledge` reads. `CreateTreadRepo`/`SetTreadDeployment` generate and wake/sleep a Tread's own app deployment (`TreadDeployment`).
- `admin.proto` gained `EndMemberSessions`, separate from the existing single-session `AdminRevokeUserSessions` family in `auth.proto` — check which one a caller means before touching session-revocation code.
- Product vocabulary never reaches the wire (unchanged rule): `channel.proto:7` still the canonical citation — a Channel "is presented as a 'Tread' in the product… The wire name stays Channel."
- `optional` throughout is deliberate presence, not nullability (unchanged): `ChannelReadState.unread_count`, `DecideBenchmarkRequest.supersedes_id`, `TopoPreferences.configured`. Dropping `optional` to tidy a field silently changes meaning.
- Cross-package imports still make FILE-level breaking bite across domains (`buf.yaml`: `breaking.use: [FILE]`): `topo`/`search` import `message`, `admin` imports `workspace`/`channel`. The new `remediation.proto` and `security.proto` do not import each other — they are called from different processes, so they communicate only through the `Finding`/`Evidence` shapes each defines for itself, not a shared type.
- Never renumber or reuse a field number, never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` catches the first; nothing but discipline catches the second.
