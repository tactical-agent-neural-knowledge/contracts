# Neurons · proto

refreshed 2026-10-10 · e52a377a71d9

- 27 domains now (five new since the last refresh: `board`, `books`, `canvas`, `remediation`, `security`), always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`." Generated Go lands at `gen/go/tank/<domain>/v1/` with the Connect client in a `<domain>v1connect/` subpackage.
- `tank.board.v1` is Neuralboards: an infinite shared board whose `Frame` can hold the *running application* (`AppFrame`), not a picture of one — `board.proto:9`. `BoardObject.rev` is bumped on every write and `PutObjectsRequest.base_revs` is checked per-object, so two people editing different shapes never collide; a same-shape collision comes back in `PutObjectsResponse.conflicts` rather than being silently overwritten. Same optimistic-concurrency shape is reused by `agentctl.proto`'s `DrawOnBoardRequest`/`ArrangeBoardRequest`.
- `tank.canvas.v1` is Neuralcanvas: pages that cite what they were written from (`Source`, with a `changed` bit) and carry structured `Decision` blocks rather than prose, because — `canvas.proto:14` — "the failure of every wiki is... nobody can tell what is still true." `UpdateBlockRequest` writes one block at a time with its own `base_rev`, mirroring the board's per-object concurrency.
- `tank.books.v1` is Neuralbooks: a double-entry-under-the-hood ledger surfaced as customers/invoices/payments/expenses, all amounts integer cents. `Invoice.share_url`/`pay_url` are mint-once, read-once credentials — `GetInvoiceRequest.rotate` is the only way back if a business loses the link, because the token is stored as a hash and cannot be read back even by TANK (`books.proto:156-164`). Same pattern as `Settings.stripe_secret_key`: write-only, read back only as `stripe_key_hint`'s last four characters.
- `tank.remediation.v1` and `tank.security.v1` are the two halves of Neuralsecurity and must stay two different programs — `remediation.proto:9-19`: the security registry (`tank.security.v1.Control`/`Finding`) judges and can't run anything; the remediation engine (agent control plane) fixes and can't touch a control, probe or framework mapping. `Remediation.judge_principal`/`fix_principal` are recorded and the engine refuses a submission where they're equal.
- `security.proto`'s `Control` model is deliberately pessimistic: `ControlState.NOT_YET` is the honest home of "probably true, can't evidence it", and a stale check reports `UNKNOWN` rather than its last good answer (`security.proto:38-41`) — a flattering registry is called out as worse than none. `FrameworkClause`/`ClauseCoverage` are views *derived* from controls, never a second set of facts.
- `remediation.proto`'s `Disposition` defaults to `PROPOSE` (a PR a human merges); `AUTO_APPLY` requires a declared `Class` with a mandatory `test_requirement`, `reversible`+`undo`, and is categorically forbidden when `Class.lockout_risk` is true, whatever else the class declares.
- Product vocabulary never reaches the wire. `proto/tank/channel/v1/channel.proto:7`: a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." A Radar is `CHANNEL_TYPE_MONITOR = 5`. The same split now covers Neuralboards/Neuralbooks/Neuralcanvas: wire packages `board`/`books`/`canvas`, product names only in comments and client copy.
- Unread-count trap, unchanged: `Channel.last_seq` (channel.proto:44) still says "unread = last_seq - last_read_seq", while `ChannelReadState.unread_count` documents why that's wrong (thread replies and deletes also consume a `channel_seq`). Use `unread_count`.
- `optional` marks deliberate presence throughout, not nullability — same convention extends to the new domains: `AgentctlPolicySummary`-adjacent fields aside, e.g. `UpdateCanvasRequest.set_blocks`/`set_sources` pair a value with an explicit "apply this" bit rather than relying on emptiness.
- `proto/tank/agentctl/v1/agentctl.proto` is the runner ↔ control-plane contract only — never the messaging core directly. Since the last refresh it grew: Neuralbooks/Neuralcanvas/Neuralboards runner-facing RPCs (`BooksSummary`, `WriteUpThread`, `DrawOnBoard`, etc., importing `board.proto`/`books.proto`/`canvas.proto` directly); `PolicySummary.tools_gate_destructive` — added because the destructive-tool gate patterns existed in policy and were evaluated control-plane-side but were never told to the sandbox, so "the gate the policy promised could not open and the command simply ran" (agentctl.proto:201-209); and `RunContext.task_class` (`single_area` vs `multi_area`) plus `skip_neural_knowledge` for measuring the Neural Knowledge layer's effect A/B.
- `ControlService.RefreshNeuralKnowledge` is what fires this very refresh: it finds a Tread with access to the repo, keeps one standing thread per repo, and is idempotent while a refresh is already running for that repo.
- `tank.agent.v1.TreadSettings` (agent.proto) gained `pull_requests` ("review" default vs "merge_when_green" — TANK watches checks and merges) and `pr_reviewer_ids`; `TreadDeployment`/`CreateTreadRepo`/`SetTreadDeployment` added TANK-hosted repos+deploys as a premium-workspace feature, separate from `SetUpRepoPreviews` (a PR into a workspace's *own* already-connected repo adding a preview-reporting workflow — never a push to main, never a side effect of anything else).
- Cross-package imports make FILE-level breaking bite across domains: `topo`/`search` import `tank.message.v1`; `admin` imports `tank.workspace.v1`+`tank.channel.v1`; `agentctl`/`events` now also import `board.proto`/`books.proto`/`canvas.proto`. A field removed from any of these fails the breaking check in every file that merely references it.
- Adding a domain needs only a new `proto/tank/<domain>/v1/<domain>.proto` plus `make gen` (managed mode supplies `go_package`, `PACKAGE_VERSION_SUFFIX` is already exempted in `buf.yaml`) — but remember `gen/ts/src/index.ts` is hand-written and will not pick it up; `board`, `books`, `canvas`, `remediation`, `security` are all missing from it right now.
- Never renumber or reuse a field number, never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` catches the first; nothing but discipline catches the second.
