# Neurons · proto

refreshed 2026-10-08 · a887d51f4d82

- 27 domains now, one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`." This refresh added five: `board`, `books`, `canvas`, `remediation`, `security`.
- `board` (Neuralboards) is an infinite board whose `Frame` (an `ObjectKind`) can hold the running application, not just a picture of one — see `board.proto:7-9`. `BoardService` also covers templates (`SaveBoardTemplate`), export (`ExportBoard` to raster/slice/embed, `BoardSlice`), a CI hook (`ReportBoardSourceRequest`/`BoardSource` — "a workspace's own CI can tell TANK where its build is"), journeys-as-tests (`GenerateTestRequest`/`FlowStep`), and `DeriveDiagramRequest` for diagrams drawn from a real schema/infra file rather than freehand.
- `books` (Neuralbooks) is double-entry bookkeeping run by an agent: `Settings`, `Customer`, `Invoice`/`InvoiceLine`, `Payment`, `Expense`, `CashSummary`. Amounts are integer cents; ids are Snowflake strings like everywhere else. `InvoiceStatus` is a one-way state machine (`DRAFT → SENT → OVERDUE → PAID`, or `VOID`); `chase_every_days` on `Settings` drives the agent's unpaid-invoice nudges. Also carries bank import/matching (`ImportBankTransactionsRequest`, `MatchBankTransactionRequest`) and receipt-driven expenses (`ReadReceiptRequest`).
- `canvas` (Neuralcanvas) is pages that remember what they were written from: `Canvas.Source` cites the threads/decisions/repos behind a page, and the doc comment states the thesis directly — "the failure of every wiki is not that writing is hard, it is that nobody can tell what is still true." `BlockKind.BLOCK_KIND_DECISION` and `BLOCK_KIND_LIVE` are the two block kinds that aren't plain rich text: a decision is kept as structure, a live block is a real figure current when the page is read. `AskRequest`/`AskResponse` is Q&A over a workspace's pages.
- `remediation` is explicitly split from `security`: the control registry (judge, lives in the messaging core / `security.proto`) submits a `Finding` across the boundary to the remediation engine (fixer, lives in agent-control / `remediation.proto`), and neither can do the other's job — `remediation.proto:9-19` states this is deliberate ("a system that can mark its own homework is not a security system"). `Disposition` defaults to `PROPOSE` (a PR a human merges); `AUTO_APPLY` is narrow, declared per `Class`, reversible, and never allowed to lock an operator out; `REFUSED` is a first-class outcome, not an error. `Finding.finding_id` + `control_version` is the dedup key — a finding against a since-changed control is stale and must be re-reviewed, not executed.
- `security` is Neuralsecurity's own registry: `Control` is the only primitive ("frameworks are views over them," `security.proto:11-16`); a `FrameworkClause` (e.g. SOC 2) maps onto controls and is never a second set of facts. `ControlState` has five honest values plus `UNKNOWN`, and `UNKNOWN` is forced whenever a check hasn't run recently — a stale check must never report its last answer. `CheckKind.CHECK_KIND_NONE` means a control can only ever be `NOT_YET`/`UNKNOWN`, never `MET`, until a check exists. `ControlCategory.CONTROL_CATEGORY_AGENT` is its own family, not folded into `APPLICATION`, because the agent runtime is a liability nobody else selling into a security review carries.
- Product vocabulary never reaches the wire. `proto/tank/channel/v1/channel.proto:7`: a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." A Radar is `CHANNEL_TYPE_MONITOR = 5`, implemented in `tank.monitor.v1`.
- Unread-count trap, and the two comments disagree: `Channel.last_seq` (channel.proto:44) still says "unread = last_seq - last_read_seq", while `ChannelReadState.unread_count` (channel.proto:77-85) documents why that arithmetic is wrong — thread replies and deleted messages also consume a `channel_seq`. Use `unread_count`; it is `optional` so a client can tell "server said zero" from an older server saying nothing.
- `optional` is used throughout as deliberate presence, not as nullability: unchanged-field semantics in `UpdateChannelRequest` / `SetChannelPreferenceRequest`, "this replaces nothing" in `DecideBenchmarkRequest.supersedes_id` (topo.proto), and the empty-vs-unconfigured distinction in `TopoPreferences.configured` (workspace.proto). Dropping `optional` to tidy a field silently changes meaning.
- `proto/tank/agentctl/v1/agentctl.proto` (1045 lines, the largest file) is the runner ↔ control-plane contract only: the in-sandbox runner talks to agent-control and never to the messaging core, authenticated by the per-run `RUN_TOKEN`, all ids Snowflake decimal strings. It now imports `board`, `books` and `canvas` too. This refresh's addition, `ControlService.BindChannelRepo`/`SetChannelRepoAccess`/`SetChannelAgentSettings`/`SetWorkspaceAgentPolicy` etc., exists because the messaging core had been issuing INSERT/DELETE directly against schema `agent` (only green in CI, where the test fixture self-grants DML) when its real grant is USAGE+SELECT; these six narrow RPCs are the boundary and deliberately take no table-and-statement escape hatch.
- `proto/tank/events/v1/events.proto` is the NATS JetStream envelope; this refresh added `CanvasBlockChanged`/`CanvasChanged`/`CanvasEditing` (subjects `evt.{ws}.canvas.{canvas}` / `typ.{ws}.canvas.{canvas}`) and the board equivalents `BoardObjectsChanged`/`BoardChanged`/`BoardPointer` (`evt.{ws}.board.{board}` / `typ...`), following the existing per-object-diff pattern so two people editing different blocks/shapes see each other instead of a whole-document reload. `AuditLogged` is internal — the gateway never fans it out to clients.
- `proto/tank/realtime/v1/realtime.proto` is the WebSocket gateway, binary protobuf by default (`?enc=json` only for debugging); `Subscribe`/`Unsubscribe` gained `canvas_ids`/`board_ids` this refresh, and `ClientFrame`/`ServerFrame` gained `canvas_editing`/`board_pointer` oneof members to match. `Event.cursor` is the JetStream stream sequence the client persists and replays with `Resume`; `PresenceSubscribe` caps at 500 ids and *replaces* the set rather than adding to it.
- `proto/tank/richtext/v1/richtext.proto` holds the `RichText` AST and states the rule plainly: "Markdown is never the storage format." Anything accepting user-authored text should take `RichText`, not a string.
- `proto/tank/blocks/v1/blocks.proto` is the agent UI vocabulary — `PlanCard`, `DiffPreview`, `CiStatus`, `ApprovalPrompt`, `ToolLog`, `StatusCard`, `FilePreview` — plus `GateKind` (PLAN, SCOPE_CHANGE, MERGE, DEPLOY, DESTRUCTIVE_TOOL, BUDGET_INCREASE). A `BlockAction` travels client → server → owning agent as an event, not as an RPC.
- `proto/tank/topo/v1/topo.proto` separates derived marks (always `MARK_STATUS_OPEN`, never stored, no `created_by_user_id`) from stored ones with a real lifecycle; only stored marks ever produce a `TopoMarkUpdated` event. This refresh added `GetBriefingResponse.hours`/`BriefingHour` (Home's day ring) and `BriefingSetup` (the first-week setup checklist: goal set, GitHub connected, agent summoned, someone invited, avatar set).
- Cross-package imports are real and make FILE-level breaking bite across domains: `agentctl` now imports `agent`, `blocks`, `board`, `books`, `canvas`; `events` imports `board` and `canvas` too; `topo` and `search` import `tank.message.v1`; `admin` imports `tank.workspace.v1` and `tank.channel.v1`. A field removed from any imported file fails the breaking check in every file that merely references it.
- Adding a domain needs only a new `proto/tank/<domain>/v1/<domain>.proto` plus `make gen`: managed mode supplies `go_package` unless you add one explicitly, and lint's `PACKAGE_VERSION_SUFFIX` exemption is already in `buf.yaml`. Remember the TS barrel at `gen/ts/src/index.ts` is hand-written and will not pick it up — it still omits `board`, `books`, `canvas`, `remediation` and `security` along with the older gaps.
- Never renumber or reuse a field number, and never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` / the PR's breaking check catches the first; nothing but discipline catches the second.
