# Neurons · proto

refreshed 2026-10-11 · e52a377a71d9

- 27 domains now (up from 22), one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. New since the last refresh: `board`, `books`, `canvas`, `remediation`, `security`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`."
- `proto/tank/security/v1/security.proto` is Neuralsecurity Phase 0: "Controls are the primitive; frameworks are views over them" — one set of facts (`Control`, owner + check + evidence query), a `FrameworkClause` (SOC 2 today) only ever maps onto existing controls, never adds a second set of facts. `ControlState` is deliberately pessimistic: `NOT_YET` covers "probably true but unevidenced", `UNKNOWN` is what a stale check reports instead of its last answer, and `NOT_APPLICABLE` requires a mandatory `reason` so a control can't quietly disappear.
- `proto/tank/remediation/v1/remediation.proto` is the seam between the half that judges and the half that fixes, and by design they are not the same program: the control registry (messaging core) submits a finding, the remediation engine (agent control plane, holds the GitHub App/sandboxes/gate engine) is the only thing that writes code — the registry can't run anything and the engine can't change a control. Propose-only by default (`AUTO_APPLY` is a short, declared allowlist); every remediation must carry the regression test it's held to; a finding fans out to every repo/workspace the check applies to, recorded per-target.
- `proto/tank/board/v1/board.proto` (549 lines) is Neuralboards: an infinite board whose difference from any other canvas is `Frame.app` — a frame can hold the running application itself, not a picture of one. `ObjectKind` covers frame/rect/ellipse/line/arrow/text/sticky/image/connector/draw; boards use board coordinates (`Rect.x/y/w`), not screen pixels.
- `proto/tank/books/v1/books.proto` (343 lines) is Neuralbooks: settings, customers, invoices, payments, expenses, cash summary. `Invoice.share_url` (line 86) is created once, at create-or-send time, and only rotatable through an explicit `rotate = true` on the update request (line 164) — never silently reissued.
- `proto/tank/canvas/v1/canvas.proto` (302 lines) is Neuralcanvas: pages that cite the thread they were written from, with per-block revisions and a decision ledger.
- Unread-count trap, and the two comments disagree: `Channel.last_seq` (channel.proto:44) still says "unread = last_seq - last_read_seq", while `ChannelReadState.unread_count` (channel.proto:77-85) documents why that arithmetic is wrong — thread replies and deleted messages also consume a `channel_seq`. Use `unread_count`; it is `optional` so a client can tell "server said zero" from an older server saying nothing.
- `optional` is used throughout as deliberate presence, not nullability: unchanged-field semantics in `UpdateChannelRequest`, "this replaces nothing" in `DecideBenchmarkRequest.supersedes_id` (topo.proto), the empty-vs-unconfigured distinction in `TopoPreferences.configured` (workspace.proto). Dropping `optional` to tidy a field silently changes meaning.
- `proto/tank/workspace/v1/workspace.proto` is the biggest legacy file (721 lines) and `GetBootstrap` is its point: one call on app open, everything else lazy. Caps members at 200, the entire reason `ListMembersRequest.query` exists.
- `proto/tank/agentctl/v1/agentctl.proto` (1045 lines, the largest file) is the runner ↔ control-plane contract only, authenticated by the per-run `RUN_TOKEN`, all ids Snowflake decimal strings. This refresh added `skip_neural_knowledge` (bool, on both `StartRunRequest` and `OpenThreadRequest`) and `RunContext.task_class` (string), plus the `RefreshNeuralKnowledge` RPC — the very mechanism regenerating this file.
- `proto/tank/agent/v1/agent.proto` carries the matching Tread-side settings: `TreadSettings.auto_accept_plans` (skip the plan gate), `pull_requests` ("review" mentions `pr_reviewer_ids`, "merge_when_green" has TANK watch checks and merge), and `read_neural_knowledge` (gate for whether this layer is even consulted).
- `proto/tank/admin/v1/admin.proto` (449 lines) gained `EndMemberSessions` this cycle, alongside the existing session RPCs in `auth.proto` (`ListSessions` / `RevokeSession` / `AdminRevokeUserSessions`) — two different services can end a session; check which one a caller actually means.
- `proto/tank/richtext/v1/richtext.proto` holds the `RichText` AST and states the rule plainly: "Markdown is never the storage format." Anything accepting user-authored text should take `RichText`, not a string.
- Cross-package imports are real and make FILE-level breaking bite across domains: `topo` and `search` import `tank.message.v1`, `admin` imports `tank.workspace.v1` and `tank.channel.v1`. A field removed from `message.proto` fails the breaking check in files that merely reference it.
- Never renumber or reuse a field number, and never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` / the PR's breaking check catches the first; nothing but discipline catches the second.
