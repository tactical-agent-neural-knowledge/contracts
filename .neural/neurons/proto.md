# Neurons · proto

refreshed 2026-10-08 · a887d51f4d82

- 27 domains now (was 22), one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. New since the last refresh: `board`, `books`, `canvas`, `remediation`, `security`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`."
- Product vocabulary never reaches the wire. `channel.proto:7`: a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." Same pattern elsewhere: a Radar is `CHANNEL_TYPE_MONITOR`, `board.v1`/`canvas.v1` back Neuralboards/Neuralcanvas, `books.v1` backs Neuralbooks.
- `option go_package` is set explicitly in 9 files even though managed mode in `buf.gen.yaml` would supply it anyway: `billing`, `books`, `canvas`, `catalog`, `monitor`, `platform`, `remediation`, `security`, `topo`. Harmless duplication (managed mode's `override` wins), but a reason to not assume "no explicit option" when checking a new file against the prefix.
- `proto/tank/agentctl/v1/agentctl.proto` is the runner <-> control-plane contract: `RunnerService` has ~40 RPCs, one per tank tool the runner uses in a thread (PostToThread, PostPlan, AskForApproval, BooksCreateInvoice, DrawOnBoard, OpenPullRequest, …) — the tool surface and this file are the same list, so a new tank tool means a new RPC here first. All ids are Snowflake decimal strings; auth is the per-run `RUN_TOKEN`.
- `PolicySummary.tools_gate_destructive` (agentctl.proto field 9) was added 2026-10-07: before it existed the control plane evaluated `destructive_tool` deny patterns but never told the sandbox about them, so the gate they implied could never open. Any policy field the runner must enforce locally has to be mirrored here explicitly — the control plane being authoritative doesn't help if the runner can't see the rule.
- `remediation.proto` and `security.proto` (Neuralsecurity) are a deliberately split pair: `security.v1` (control registry, in the messaging core) decides what's true and wrong; `remediation.v1` (agent control plane) is the only side that can write code, via a proposed pull request. Documented as four rules in `remediation.proto`'s header: propose-only by default (`AUTO_APPLY` is a short, declared exception list), every fix ships its own regression test, fixes target the finding's class and fan out to every repo it applies to, and every remediation records the run that drove it. Neither side may do the other's job — "a system that can mark its own homework is not a security system."
- `books.proto`: amounts are integer cents, ids are Snowflake strings. `GetInvoiceRequest.rotate` (field 3, added in the previous refresh cycle) mints a new share link and kills the old one atomically — the share token is stored as a hash and an ordinary `GetInvoice` never returns `share_url` again once issued, so rotate is the only recovery if a business loses the link.
- `events.proto` carries ephemeral, never-stored frames alongside durable ones in the same `Envelope`/`oneof` shape: `BoardPointer`/`CanvasEditing` (presence-like, on `typ.{ws}.board.{board}` / `typ.{ws}.canvas.{canvas}`) versus `BoardObjectsChanged`/`CanvasBlockChanged` (durable, carry a `version`). `realtime.proto`'s `ClientFrame`/`ServerFrame` oneofs grew matching cases (`canvas_editing`, `board_pointer`) — a new realtime frame kind touches both files together.
- `optional` is used throughout as deliberate presence, not nullability: unchanged-field semantics in `UpdateChannelRequest`, "this replaces nothing" in `DecideBenchmarkRequest.supersedes_id`. Dropping `optional` to tidy a field silently changes meaning.
- `workspace.proto` (721 lines, biggest file) still centers on `GetBootstrap` — one call on app open, everything else lazy. `topo.proto`'s `GetBriefingResponse` grew `BriefingHour`/`BriefingSetup` this cycle for Home's day ring and first-week setup cards.
- Cross-package imports make FILE-level breaking bite across domains: `events.proto` now also imports `board.v1` and `canvas.v1`; `topo`/`search` import `message.v1`; `admin` imports `workspace.v1` and `channel.v1`. A field removed from an imported file fails the breaking check in every file that references it.
- `gen/ts/src/index.ts` is hand-written and covers only 14 of the 27 packages (missing all 5 new domains plus admin, billing, catalog, command, huddle, monitor, platform, topo). Adding a domain's `.proto` and running `make gen` does not add it to this barrel — deep imports are the documented fallback.
- Never renumber or reuse a field number, never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` / the PR's breaking check catches the first; nothing but discipline catches the second.
