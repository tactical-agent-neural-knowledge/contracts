# Neurons · proto

refreshed 2026-10-09 · e52a377a71d9

- 27 domains, one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`." Five domains since the last refresh: `board`, `canvas`, `books`, `remediation`, `security`.
- Product vocabulary never reaches the wire, and the newest proof is `admin.proto`'s `EndMemberSessions` (ends sessions, leaves membership alone) sitting next to `RemoveMember` (ends membership, cascades sessions) — two RPCs because "the laptop went missing" and "the person left" are different asks, not one action named for the UI.
- `proto/tank/security/v1/security.proto` and `proto/tank/remediation/v1/remediation.proto` are a deliberate pair, not one domain split in two: security's `ControlRegistry` judges (a `Control` is `MET`/`PARTLY`/`NOT_YET`/`NOT_APPLICABLE`/`UNKNOWN`, never flattered), remediation's engine only fixes (`SubmitFinding` → a pull request, `DISPOSITION_AUTO_APPLY` restricted to a short declared `Class` list). Neither service has an RPC for the other's job — `remediation.proto:291` spells out that there is deliberately no RPC here that changes a control.
- `proto/tank/books/v1/books.proto`'s `GetInvoiceRequest.rotate` mints a new share link and kills the old one atomically; the token is stored as a hash so `share_url` is unreadable after the invoice is sent except through this one escape hatch (admin-only, by design — see the comment at `books.proto:155`).
- `proto/tank/board/v1/board.proto`'s whole reason to exist is `AppFrame`: a frame can hold the running application at a commit (`drawn_from_sha`, `moved_on` when the app has since shipped), not a screenshot of one. `proto/tank/canvas/v1/canvas.proto` is the written counterpart — a page that cites what it was written from and flags `needs_revisiting` when that changes, plus `Live` blocks the server fills in on read so a page is never stale about its own numbers.
- `proto/tank/agentctl/v1/agentctl.proto` grew from the runner↔control-plane contract into the agent's whole tool surface: Neuralbooks (`BooksSummaryRequest`/`CreateInvoice`/...), Neuralcanvas (`WriteUpThread`/`ReadCanvas`/`AskCanvas`), Neuralboards (`ListBoards`/`ReadBoard`, drawing), and board-product-only tools gated by `RunContext.product_run`. Still: all ids are Snowflake decimal strings, auth is the per-run `RUN_TOKEN`, and the runner never talks to the messaging core directly.
- `events.proto` and `realtime.proto` gained symmetric pairs for both new domains: `CanvasBlockChanged`/`CanvasChanged`/`CanvasEditing` and `BoardObjectsChanged`/`BoardChanged`/`BoardPointer`, each mirrored into `ClientFrame`/`ServerFrame` oneofs in realtime.proto. `BoardPointer.kind` ("user" | "agent") is what lets an agent's cursor render distinctly while it draws beside people in a live board.
- `optional` is still deliberate presence, not nullability — see `admin.ListMembersRequest.deactivated` and the `Channel`/`workspace` fields noted in earlier refreshes. Dropping it to tidy a field silently changes meaning.
- Cross-package imports keep widening the FILE-level breaking blast radius: `events.proto` now imports `tank.board.v1` and `tank.canvas.v1` on top of `admin`, `agent`, `blocks`, `channel`, `files`, `huddle`; `agentctl.proto` imports `agent`, `blocks`, `board`, `books`, `canvas`. A field removed from any of those fails the breaking check in every importer, not just its own file.
- `option go_package` is now hand-written in 9 of 27 files (`billing`, `catalog`, `monitor`, `platform`, `topo`, plus the four newest: `canvas`, `books`, `remediation`, `security`) — managed mode supplies the rest via `go_package_prefix` in `buf.gen.yaml`. A new domain copying one of these files must match the managed prefix (`github.com/.../contracts/gen/go/tank/<domain>/v1;<domain>v1`) exactly.
- `gen/ts/src/index.ts` is still a hand-maintained barrel and has not kept pace with new domains: it covers 14 of 27 packages and is missing every one of the five added since the last refresh (`board`, `canvas`, `books`, `remediation`, `security`) plus eight older ones (`admin`, `billing`, `catalog`, `command`, `huddle`, `monitor`, `platform`, `topo`). Deep imports remain the only path to those.
- Never renumber or reuse a field number, and never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` / the PR's breaking check catches the first; nothing but discipline catches the second.
