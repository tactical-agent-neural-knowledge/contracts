# Neurons · proto

refreshed 2026-10-09 · e52a377a71d9

- 27 domains now (was 22 at the last refresh): `board`, `books`, `canvas`, `security` and `remediation` were added since, each `proto/tank/<domain>/v1/<domain>.proto`, package `tank.<domain>.v1`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`."
- `remediation.proto` (new) is the contract between the messaging core's control registry (decides what is wrong) and the agent control plane's remediation engine (the only thing that can write code): no RPC here changes a control, retires a probe, or marks a finding resolved, and the engine refuses a remediation whose judge and fix principals are the same. `AUTO_APPLY` is a declared, narrow Class with a reverse and a gate; propose-only (a PR a human merges) is the default disposition.
- `agentctl.proto`'s `ControlService` grew six narrow RPCs (`BindChannelRepo`, `UnbindChannelRepo`, `SetChannelRepoAccess`, `CreateGitHubConnectState`, `SetChannelAgentSettings`, `SetWorkspaceAgentPolicy`) because the messaging core (`api`) was issuing INSERT/DELETE directly against schema `agent`, which it is granted only USAGE + SELECT on — green only in CI, where the test fixture grants itself DML. There is deliberately no generic "write a table" RPC and there will not be one; each call is typed to one thing `api` needs done.
- `agentctl.proto`'s `RunnerService` is the single service the in-sandbox runner calls — authenticated with the per-run `RUN_TOKEN`, never talking to the messaging core directly — and its ~40 RPCs are a near 1:1 mirror of every tool a run has (PostToThread, PostPlan, AskForApproval, the Books*/Board*/Canvas* families, OpenPullRequest, RequestCiWatch, SessionStore*). Adding a tank tool means adding an RPC here first.
- `admin.proto` gained `EndMemberSessions` (additive, clean `buf breaking`): ends every session a member holds without touching their membership or any API/bot token — the admin action for "a laptop went missing" as opposed to "a person left". Response carries `sessions_ended` so "it worked" and "there were none" (the common case) read differently.
- `books.proto`'s `GetInvoiceRequest.rotate` mints a new share link and kills the old one atomically. The share token is stored as a hash — an ordinary `GetInvoice` always returns an empty `share_url`, the link is readable only once, at creation/send — so `rotate` is the only recovery when a business loses it. Admin only.
- `board.proto` (new domain): an infinite board shared by people and an agent; its `Frame` can hold the running application itself rather than a picture of one (`OBJECT_KIND_FRAME`, see `Frame.app`). Coordinates in every message are board coordinates, not screen pixels.
- `canvas.proto` (new domain, Neuralcanvas): a page cites the threads, decisions and repositories it was written from, and can go stale when those move — stated as the file's whole reason for existing, not just a field.
- `security.proto` (new domain, Neuralsecurity Phase 0): controls are the one primitive, frameworks (SOC 2 first) are views over them — never a second set of facts. `ControlState` is deliberately allowed to be bad: `NOT_YET` even when everyone is "fairly sure", `UNKNOWN` rather than reusing a stale last answer.
- Product vocabulary never reaches the wire, still true: `channel.proto:7` — a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." A Radar is `CHANNEL_TYPE_MONITOR = 5`, implemented in `tank.monitor.v1`.
- `optional` throughout is deliberate presence, not nullability (unchanged-field semantics in `UpdateChannelRequest`, "this replaces nothing" in `topo.proto`'s `supersedes_id`, empty-vs-unconfigured in `workspace.proto`'s `TopoPreferences.configured`). Dropping `optional` to tidy a field silently changes meaning.
- `events.proto` is the NATS JetStream envelope: `Envelope.id` is the `Nats-Msg-Id` idempotency key, payload is `google.protobuf.Any`, subjects are `evt.{ws}.ch.{channel}`, `.thread.{root}`, `.user.{uid}`, `.ws`. `AuditLogged` is internal only — the gateway never fans it to clients.
- Cross-package imports make FILE-level breaking bite across domains: `agentctl` now imports `agent`, `blocks`, `board`, `books` and `canvas`; `topo`/`search` import `message`; `admin` imports `workspace`/`channel`. A field removed from an imported file fails the breaking check in every file that references it, not just its own.
- Never renumber or reuse a field number, never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` catches the first; only discipline and review catch the second.
