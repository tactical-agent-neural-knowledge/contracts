# Neurons · proto

refreshed 2026-10-14 · 6e371811ddb2

- 27 files across 26 domains now (one package each, `proto/tank/<domain>/v1/<domain>.proto`, package `tank.<domain>.v1`), up from 22: `board`, `books`, `canvas`, `remediation` and `security` landed since the last refresh. `CLAUDE.md`: "One proto package per domain, version suffix `v1`."
- `proto/tank/board/v1/board.proto` is Neuralboards: an infinite board whose `Frame` can hold the *running application* (`AppFrame`, keyed by `repo`/`ref`/`path`/`sha`), not a picture of one — `moved_on`/`moved_note` tell a viewer the app has shipped past what the frame was drawn from. Objects use optimistic concurrency per-object (`BoardObject.rev`, `PutObjectsRequest.base_revs`), not whole-board locking.
- `proto/tank/books/v1/books.proto` is Neuralbooks: double-entry bookkeeping surfaced as customers/invoices/payments/expenses, all amounts integer cents. `Settings.stripe_secret_key` is write-only by convention (set to store, empty to leave alone, read back only as `stripe_key_hint`'s last four chars) — the same shape as `Invoice`'s share token, which is stored hashed and cannot ever be read back, only rotated via `GetInvoiceRequest.rotate`.
- `proto/tank/canvas/v1/canvas.proto` is Neuralcanvas: pages that cite the threads/decisions/repos they were written from and mark themselves stale when those move — the explicit fix for "every wiki quietly goes out of date." `BlockKind.BLOCK_KIND_LIVE` is a figure read live from the workspace at render time, not stored text.
- `proto/tank/remediation/v1/remediation.proto` and `proto/tank/security/v1/security.proto` are the two halves of Neuralsecurity and are deliberately kept in separate domains/services: `security` is the control registry (judges — `ControlState` MET/PARTLY/NOT_YET/NOT_APPLICABLE/UNKNOWN, never flattered, a stale check reports UNKNOWN not its last answer), `remediation` is the fix engine (acts — opens the PR, propose-only by default, AUTO_APPLY is a short declared allowlist). Comment in remediation.proto: "A system that can mark its own homework is not a security system."
- `proto/tank/agent/v1/agent.proto`'s `TreadSettings` (added this cycle) is the Tread switchboard: `pull_requests` is `"review"` (default, mentions `pr_reviewer_ids`) or `"merge_when_green"`; `merge_allowed` is the separate on/off for whether TANK may merge at all — the two combine so a Tread can require human merge regardless of `pull_requests`. `ListTreadSecurity` (same file) surfaces Neuralsecurity's last verdict per connected Tread.
- Product vocabulary never reaches the wire. `proto/tank/channel/v1/channel.proto:7`: a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." Same discipline in the new files: Neuralboards/Neuralbooks/Neuralcanvas/Neuralsecurity are product names in comments only, packages are `board`/`books`/`canvas`/`security`/`remediation`.
- Unread-count trap, unchanged: `Channel.last_seq` (channel.proto:44) still says "unread = last_seq - last_read_seq", while `ChannelReadState.unread_count` (channel.proto:77-85) documents why that arithmetic is wrong. Use `unread_count`.
- `optional` is used throughout as deliberate presence, not nullability — e.g. `UpdateChannelRequest`, `DecideBenchmarkRequest.supersedes_id`, `TopoPreferences.configured`. Dropping `optional` to tidy a field silently changes meaning.
- `proto/tank/workspace/v1/workspace.proto` (719 lines) still the biggest file; `GetBootstrap` is its point — one call on app open, everything else lazy.
- `proto/tank/agentctl/v1/agentctl.proto` is the runner ↔ control-plane contract only, authenticated by the per-run `RUN_TOKEN`, ids are Snowflake decimal strings; it carries `tank.agent.v1.TreadSettings` across the boundary rather than redefining it.
- Cross-package imports make FILE-level breaking bite across domains: `topo`/`search` import `tank.message.v1`, `admin` imports `tank.workspace.v1`/`tank.channel.v1`, `agentctl` imports `tank.agent.v1`. A field removed from an imported file fails the breaking check in every file that references it.
- Adding a domain needs only a new `proto/tank/<domain>/v1/<domain>.proto` plus `make gen` (or the npx buf fallback): managed mode supplies `go_package` unless you set it explicitly as the five newest domains do, and lint's `PACKAGE_VERSION_SUFFIX` exemption is already in `buf.yaml`. The TS barrel at `gen/ts/src/index.ts` is hand-written and will not pick it up — board/books/canvas/remediation/security all need adding by hand if TS consumers want the namespaced import.
- Never renumber or reuse a field number, and never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` / the PR's breaking check catches the first; nothing but discipline catches the second.
