- 29 domains now (grew from 22), one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`." Newest is `crew` (`crew.proto`); also newer since the last refresh: `admin`, `billing`, `blocks`, `board`, `books`, `canvas`, `catalog`, `command`, `huddle`, `monitor`, `notification`, `platform`, `remediation`, `security`, `social`, `topo`.
- Product vocabulary never reaches the wire. `proto/tank/channel/v1/channel.proto:7`: a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." `crew.proto` repeats the pattern — `Treads` enum picks which channels a member works in, but the message type stays `Member`/`Preset`, not "Crew member".
- `TreadSettings` (`proto/tank/agent/v1/agent.proto:263`) is the per-Tread policy block: `auto_accept_plans` skips the plan gate, `pull_requests` is `"review"` (default — posts the PR, mentions `pr_reviewer_ids`) or `"merge_when_green"` (TANK watches checks and merges itself), and `strongest_model` forces Opus from the start instead of escalating. Set via `SetTreadSettings`; also carried in `agentctl.proto:1056` so the runner gets the same policy a run started under.
- `crew.proto`: `Member.model = ""` means "use the policy default"; `daily_cap_usd`/`concurrent_cap = 0` mean no cap / fall back to the workspace's. `RemoveMember` stops future runs under that handle but does not delete what it already said in a Tread.
- Unread-count trap, and the two comments disagree: `Channel.last_seq` (channel.proto:44) still says "unread = last_seq - last_read_seq", while `ChannelReadState.unread_count` (channel.proto:77-85) explains why that's wrong — thread replies and deletions also consume a `channel_seq`. Use `unread_count`, which is `optional` so a client can tell "server said zero" from "older server said nothing."
- `optional` is deliberate presence throughout, not nullability: unchanged-field semantics in `UpdateChannelRequest`/`SetChannelPreferenceRequest`, "this replaces nothing" in `DecideBenchmarkRequest.supersedes_id` (topo.proto), empty-vs-unconfigured in `TopoPreferences.configured` (workspace.proto). Dropping `optional` to tidy a field silently changes its meaning.
- `proto/tank/agentctl/v1/agentctl.proto` is the runner ↔ control-plane contract only — never the messaging core — authenticated by a per-run `RUN_TOKEN`, all ids Snowflake decimal strings. `RunPhase` drives the runner's permission mode; `StartRunRequest.mode = "neural"` skips planning and works directly in whatever repo the Tread is bound to.
- `proto/tank/events/v1/events.proto` is the NATS JetStream envelope: `Envelope.id` is the `Nats-Msg-Id` idempotency key, payload is `google.protobuf.Any`, subjects are `evt.{ws}.ch.{channel}`, `.thread.{root}`, `.user.{uid}`, `.ws`. `AuditLogged` is internal-only — never fanned out to clients.
- `proto/tank/realtime/v1/realtime.proto` is the WebSocket gateway, binary protobuf by default (`?enc=json` for debugging only). `Event.cursor` is the JetStream stream sequence a client persists and replays via `Resume`; `PresenceSubscribe` caps at 500 ids and *replaces* the subscribed set rather than adding to it.
- `proto/tank/richtext/v1/richtext.proto` holds the `RichText` AST: "Markdown is never the storage format." Anything accepting user-authored text should take `RichText`, not a string.
- `proto/tank/blocks/v1/blocks.proto` is the agent UI vocabulary — `PlanCard`, `DiffPreview`, `CiStatus`, `ApprovalPrompt`, `ToolLog`, `StatusCard`, `FilePreview` — plus `GateKind` (PLAN, SCOPE_CHANGE, MERGE, DEPLOY, DESTRUCTIVE_TOOL, BUDGET_INCREASE). A `BlockAction` travels client → server → owning agent as an event, not an RPC.
- Cross-package imports make FILE-level breaking bite across domains: `topo` and `search` import `tank.message.v1`; `admin` imports `tank.workspace.v1` and `tank.channel.v1`. A field removed from `message.proto` fails the breaking check in every file that merely references it, not just its own.
- Adding a domain needs only a new `proto/tank/<domain>/v1/<domain>.proto` plus `buf generate`: managed mode supplies `go_package`, and `buf.yaml`'s `PACKAGE_VERSION_SUFFIX` lint exemption already covers the `v1` suffix. The TS barrel `gen/ts/src/index.ts` is hand-written and will not pick up a new domain on its own.
- Never renumber or reuse a field number, never remove a field before every client has shipped without it (`CLAUDE.md`). `buf breaking` / the PR's breaking-check step catches the first; nothing but discipline catches the second.
