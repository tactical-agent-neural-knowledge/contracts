# Neurons · proto

refreshed 2026-10-11 · e52a377a71d9

- 27 domains now (was 22), one package each, always `proto/tank/<domain>/v1/<domain>.proto` with package `tank.<domain>.v1`. `CLAUDE.md`: "One proto package per domain, version suffix `v1`." Five domains are new since the last refresh: `board`, `books`, `canvas`, `remediation`, `security` — Neuralboards, Neuralbooks, Neuralcanvas, and the security-posture/remediation pair.
- Product vocabulary never reaches the wire. `proto/tank/channel/v1/channel.proto:7`: a Channel "is presented as a 'Tread' in the product… The wire name stays Channel." A Radar is `CHANNEL_TYPE_MONITOR = 5`, implemented in `tank.monitor.v1`.
- Recurring convention across the new domains: per-object/per-block optimistic concurrency via `base_rev`/`base_revs`, never silent overwrite. `board.proto`'s `PutObjectsRequest.base_revs` (per shape) and `canvas.proto`'s `UpdateBlockRequest.base_rev` (per block) both report a stale write back in a `conflicts`/`conflict` field; `agentctl.proto`'s `DrawOnBoard`/`ArrangeBoard` reuse the same board types and the same conflict contract even when the writer is an agent.
- Recurring convention: write-once, read-redacted secrets. `books.proto`'s `Settings.stripe_secret_key` only round-trips as `stripe_key_hint` (last 4 chars); an invoice's `share_url` token is stored hashed and only `GetInvoiceRequest.rotate` (admin-only) can produce a fresh one, killing the old link; `agent.proto`'s `SetUpRepoPreviews` returns a `token` readable exactly once, `rotate_token` the only recovery. Same shape, three unrelated domains — don't expect any of these to round-trip on a plain read.
- `proto/tank/security/v1/security.proto`: `Control` (line 130) is the sole primitive; frameworks like SOC 2 are pure derived views (`FrameworkCoverage`/`ClauseCoverage`) never a second source of truth. `ControlState.UNKNOWN` is enforced, not optional — stale `Evidence` or an expired `Attestation` must force `UNKNOWN`, never report the last (possibly green) check. A control with `CheckKind.CHECK_KIND_NONE` can only ever be `NOT_YET`/`UNKNOWN`, never `MET`.
- `proto/tank/remediation/v1/remediation.proto` is deliberately a separate program from `security.proto` (file header, lines 9-19): security judges, remediation fixes (GitHub App, sandboxes, gates); the fixer has no RPC to edit a control and the judge has no RPC to run anything. `SubmitFinding` is idempotent on `(finding_id, control_version)` — resubmitting supersedes the prior remediation rather than opening a duplicate PR. `Disposition.AUTO_APPLY` is restricted to `Class`es with `reversible=true && lockout_risk=false`; every registered `Class` must declare a `test_requirement` — no fix class without a regression test.
- `proto/tank/agentctl/v1/agentctl.proto` is now the biggest file (1045 lines, +372 this refresh): the in-sandbox runner ↔ control-plane contract, authenticated by the per-run `RUN_TOKEN`, all ids Snowflake decimal strings. `PolicySummary.tools_gate_destructive` closes a real hole: the destructive-tool gate existed in policy and was evaluated control-plane-side but was never told to the sandboxed runner, so it "could not open and the command simply ran" until this field was added.
- `agentctl.proto` added narrow, single-purpose schema-boundary RPCs (`BindChannelRepo`, `SetChannelAgentSettings`, `SetWorkspaceAgentPolicy`, etc.) because the messaging core was issuing raw INSERT/DELETE against the `agent` schema that it only has SELECT on in production — those writes were "only ever green in CI," where the test fixture self-grants DML. The fix is deliberately narrow: there is and will not be a generic table+statement RPC.
- `agentctl.proto` now re-exports Neuralbooks/Neuralcanvas/Neuralboards straight into the runner contract (`BooksSummary`/`CreateInvoice`/`RecordExpense`/`RecordPayment`/`Report`, `WriteUpThread`/`ReadCanvas`/`AskCanvas`, `ListBoards`/`ReadBoard`/`DrawOnBoard`/`ArrangeBoard`), importing `tank.books.v1`/`tank.canvas.v1`/`tank.board.v1` types directly so an agent run can act as the workspace's own user in those systems, not a parallel API.
- `proto/tank/events/v1/events.proto` is the NATS JetStream envelope: `Envelope.id` is the `Nats-Msg-Id` idempotency key, payload is `google.protobuf.Any`, subjects are `evt.{ws}.ch.{channel}`, `.thread.{root}`, `.user.{uid}`, `.ws`. It now also imports `board.proto`/`canvas.proto` for `BoardObjectsChanged`/`CanvasBlockChanged` etc.; `BoardPointer`/`CanvasEditing` are explicitly "never stored" ephemeral frames, same as typing/presence. `AuditLogged` stays internal-only — the gateway never fans it out to clients.
- `proto/tank/realtime/v1/realtime.proto`: `Subscribe`/`Unsubscribe` gained `canvas_ids`/`board_ids` — a client must explicitly subscribe to a canvas/board id to see other users' edits to it, having the page open is not enough. `PresenceSubscribe` still caps at 500 ids and *replaces* the set rather than adding to it.
- `proto/tank/topo/v1/topo.proto`'s new `BriefingSetup.done` (all five onboarding conditions true) and `workspace.proto`'s new `HomeLayout.setup_hidden` are independent: a user can dismiss the first-week setup cards without ever completing them.
- Cross-package imports are real and make FILE-level breaking bite across domains: `topo` and `search` import `tank.message.v1`, `admin` imports `tank.workspace.v1`/`tank.channel.v1`, and `events`/`agentctl` now import `board`/`canvas`/`books`. A field removed from one of these fails the breaking check in every file that merely references it.
- Adding a domain needs only a new `proto/tank/<domain>/v1/<domain>.proto` plus `make gen` (or `buf generate` directly, see root neurons on `make` not being installed here): managed mode supplies `go_package`, and lint's `PACKAGE_VERSION_SUFFIX` exemption is already in `buf.yaml`. The TS barrel at `gen/ts/src/index.ts` is hand-written and will not pick it up — all five new domains are already missing from it.
- Never renumber or reuse a field number, and never remove a field before every client has shipped without it (`CLAUDE.md`). `make breaking` / the PR's breaking check catches the first; nothing but discipline catches the second.
